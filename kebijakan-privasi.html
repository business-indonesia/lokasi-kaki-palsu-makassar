Kebijakan Privasi

Halaman ini menjelaskan secara ringkas bagaimana platform lokasi pelayanan Pusat Layanan Pembuatan Kaki Palsu memperlakukan informasi pengunjung. Prinsip utamanya adalah mengumpulkan sesedikit mungkin data yang diperlukan untuk menjalankan layanan dan menjaga keamanan.

Informasi yang Anda berikan

Jika Anda menghubungi kami melalui WhatsApp atau kanal komunikasi lain, Anda dapat memberikan nama, wilayah, kebutuhan alat, dan informasi yang relevan untuk konsultasi. Mohon jangan mengirim informasi sensitif yang tidak diperlukan melalui halaman publik.

Penyimpanan browser

Website publik tidak menggunakan localStorage, sessionStorage, IndexedDB, atau service worker untuk menyimpan data pengunjung. Pencarian dan navigasi publik berjalan tanpa penyimpanan browser. Administrator menggunakan cookie sesi server yang aman hanya untuk autentikasi dan CSRF; cookie tersebut diperlukan agar keamanan login tetap berfungsi.

Log teknis

Website publik tidak menggunakan sistem analitik berbasis browser. Log teknis server dapat digunakan untuk keamanan dan pemeliharaan tanpa menyimpan identitas pengunjung sebagai penyimpanan browser.

Cache browser dan proxy

Platform mengirim kebijakan HTTP no-store pada respons website agar browser dan proxy tidak diminta menyimpan salinan respons. Pengaturan ini meningkatkan kontrol privasi tetapi dapat membuat pemuatan ulang aset sedikit lebih lambat.

Keamanan

Platform menggunakan HTTPS, header keamanan, pembatasan akses direktori internal, validasi input pada area administrasi, serta pencatatan audit untuk tindakan administratif yang relevan. Tidak ada sistem web yang dapat dijamin 100% bebas risiko, sehingga pengguna tetap disarankan menghindari pengiriman data sensitif melalui kanal publik.

Hak dan pertanyaan

Untuk pertanyaan mengenai privasi atau permintaan terkait informasi yang Anda kirimkan kepada kami, hubungi Pusat Layanan Pembuatan Kaki Palsu melalui WhatsApp 0853 9484 9766.
